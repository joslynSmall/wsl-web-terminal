# 桥接与镜像（bridge）

把第三方终端应用里已经打开的终端会话，通过桥接器显示并操作到网页。

## 边界

- 包含：桥接器连入、终端会话列表、来源、环境、网页新建窗口落到哪个窗口和选什么环境与工作目录、服务启动时打印给另一侧填写的地址。
- 不包含：网页里的按键、字号、滚动（归网页呈现，本次不建域）；Host / Origin 校验（现有行为，本次不改）。

## 域内共用不变量

- 一个终端会话只属于连入它的那个桥接器；另一个桥接器报同一个会话 ID 时，后到的被忽略。
- 断开一个桥接器只移除它自己的终端会话。
- 来源名只在同时有多个来源时出现在标签标题上。
- 环境（终端实际所在系统）和来源（桥接器所在系统）是两个独立概念，不能互相冒充。
